## 2. Description of Service

Archi is a native iOS application for scanning and archiving documents. It provides:

- Document scanning via iPhone camera (Apple VisionKit)
- On-device OCR text recognition via Apple Vision — no internet required
- On-device AI metadata extraction (Gemma 4 via LiteRT) — no cloud, no external API calls
- Optional upload to a Paperless-NGX server operated by the user
